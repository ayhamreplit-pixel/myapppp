# 🚀 سيرفر ولوحة تحكم مجلد m7 (خارج app)

هذا هو المجلد الرئيسي `m7` المطلوب لسيرفرك على AlwaysData أو أي سيرفر PHP خارجي.

---

## 📌 الروابط المباشرة:
1. **لوحة التحكم الرسومية (Web Dashboard):**
   `https://ayham.alwaysdata.net/m7/` أو `https://ayham.alwaysdata.net/m7/api.php`
2. **رابط الـ API لتطبيق الأندرويد:**
   `https://ayham.alwaysdata.net/m7/api.php?action=matches`

---

## 🌟 المميزات المتاحة في لوحة m7:
* **جلب تلقائي لمباريات اليوم والأمس والغد** من YSScores مع كاش ذكي لمنع الحظر.
* **إضافة وتعديل سيرفرات المشاهدة** المتعددة لكل مباراة (سيرفر 1 FHD، سيرفر 2 HD...).
* **مشغل فيديو مدمج (HLS / m3u8)** لفحص رابط البث مباشرة قبل الحفظ.
* **تعديل شامل للنتائج والدقائق** وحالة المباراة وأسماء المعلقين والقنوات.
* **تمييز المباريات في البانر العلوي (★ بالبانر)** للتطبيق.
* **إضافة مباريات وبطولات مخصصة (+ مباراة جديدة)**.
* **تحديث مباشر وتلقائي كل 25 ثانية** مع زر تفريغ الكاش الفوري.
* **تصدير واستعادة النسخ الاحتياطية كملف JSON**.
