# 🚀 طريقة رفع ملفات السيرفر إلى مجلد m7 على AlwaysData

أهلاً بك! لقد تم تجهيز كافة ملفات الخادم ولوحة التحكم الخارجية بالكامل داخل مجلد `m7` لترفعها إلى موقعك:
**https://ayham.alwaysdata.net/m7**

---

### 📂 محتويات مجلد m7:
1. **`api.php`**: واجهة الـ REST API للتطبيق (جلب المباريات، القنوات، تسجيل جلسات الأجهزة "من يشاهد الآن"، وتحديث النتائج).
2. **`index.php`**: لوحة التحكم الخارجية الفاخرة للويب (إضافة وتعديل المباريات مع روابط الشعارات، البث المباشر، إدارة القنوات، وفصل الأجهزة المتصلة).
3. **`matches.json`**: ملف قاعدة بيانات المباريات المباشرة والنتائج.
4. **`channels.json`**: ملف قاعدة بيانات القنوات الرياضية.
5. **`sessions.json`**: ملف تتبع الأجهزة المتصلة والجلسات النشطة في الوقت الفعلي.
6. **`.htaccess`**: ملف إعدادات الحماية وتصاريح CORS لربط التطبيق.

---

### 🛠️ خطوات الرفع السريعة على AlwaysData:
1. قم بالدخول إلى لوحة تحكم AlwaysData: https://admin.alwaysdata.com
2. توجه إلى قسم **Web > Sites** أو افتح مدير الملفات **Files / FTP**.
3. داخل مجلد الموقع الرئيسي `www/` أو `public_html/`، أنشئ مجلداً باسم:
   ```
   m7
   ```
4. ارفع كافة الملفات الموجودة في مجلد `m7` إلى داخل هذا المجلد على السيرفر.
5. تأكد من إعطاء تصاريح الكتابة (Permissions 755 أو 777) لملفات الـ `.json` حتى يستطيع السيرفر حفظ المباريات والأجهزة المتصلة.

---
