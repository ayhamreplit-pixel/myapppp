# 🚀 هيكلية وخادم لوحة التحكم السحابية المحدثة لمجلد `m7`

تمت إعادة هيكلة السيرفر ولوحة التحكم بالكامل إلى **نظام طبقات منفصلة (Modular Multi-Layer Architecture)** فائق الأمان والسرعة.

---

## 📁 هيكلية ملفات مجلد `m7`:
```
m7/
├── .htaccess                  # حماية المجلدات والملفات وتوجيه الروابط النظيفة
├── index.php                  # مدخل لوحة التحكم الرئيسية (Web Admin Dashboard)
├── api.php                    # موجه الـ API المشفر لتطبيق الأندرويد
├── config/
│   └── config.php             # الإعدادات العامة ومفتاح التشفير والمسارات
├── core/
│   ├── Security.php           # طبقة التشفير وفك التشفير AES-256-CBC وحماية CSRF
│   ├── Storage.php            # طبقة التخزين الذري لملفات JSON
│   ├── AuthService.php        # توثيق الأجهزة، رصد المشاهدين الحيين، وحظر الأجهزة
│   ├── UploadService.php       # رفع الصور والشعارات مباشرة من جهازك (PNG, JPG, WEBP)
│   ├── MatchesService.php     # جلب ومعالجة المباريات المباشرة بدون أي بيانات وهمية
│   ├── ChannelsService.php    # إدارة القنوات الرياضية المباشرة
│   ├── HeroService.php        # إدارة بوسترات الهيرو وأفضل مباريات الأسبوع
│   └── AnnouncementService.php# نظام الإشعارات والتنبيهات الحية
├── views/                     # واجهات لوحة التحكم الرسومية المنفصلة
│   ├── header.php             # رأس الصفحة وتنسيقات التصميم الزجاجي الداكن
│   ├── footer.php             # النوافذ المنبثقة، رفع الصور، وأكواد JavaScript ومشغل HLS
│   ├── tab_matches.php        # إدارة جدول المباريات وتفعيل السيرفرات
│   ├── tab_channels.php       # إدارة القنوات مع رفع الشعارات من جهازك
│   ├── tab_hero.php           # إدارة بوسترات الهيرو والمباريات المميزة
│   ├── tab_slider.php         # إدارة السلايدر الترويجي
│   ├── tab_devices.php        # 👥 من يشاهد الآن؟ وإدارة الأجهزة والحظر الصارم
│   ├── tab_notifications.php  # إرسال التنبيهات
│   ├── tab_security.php       # أمان وتشفير البيانات (مفتاح الماستر + أداة الفحص)
│   └── tab_player.php         # مشغل الفيديو التجريبي
└── data/                      # المجلد المحمي للبيانات
└── uploads/                   # مجلد حفظ الصور والشعارات المرفوعة من جهازك
```

---

## 📌 الروابط المباشرة والمسارات النظيفة:
1. **لوحة التحكم الرسومية (Web Dashboard):**
   - `https://ayham.alwaysdata.net/m7/` أو `https://ayham.alwaysdata.net/m7/index.php`
2. **رابط الـ API الأساسي (مع التشفير الكامل لروابط البث):**
   - `https://ayham.alwaysdata.net/m7/api.php?action=matches` أو `https://ayham.alwaysdata.net/m7/api/matches`
3. **روابط الـ API الفرعية:**
   - القنوات: `api.php?action=channels`
   - الهيرو: `api.php?action=hero`
   - مباريات الأسبوع: `api.php?action=featured`
   - الإشعارات: `api.php?action=announcement`

---

## 🔒 نظام الحماية والتشفير المعتمد (AES-256-CBC):
- **تشفير حقيقي 100%** متوافق مع `StreamSecurityManager` في تطبيق الأندرويد.
- **مفتاح الماستر**: `TOD_SPORTS_STREAM_SECURE_KEY_2026_PRO`.
- **حماية المجلدات الحساسة**: تم منع الوصول المباشر لملفات `.json` ومجلدات `core/` و `data/` عبر `.htaccess`.
- **لا توجد أي بيانات وهمية أو استرداد افتراضي مصطنع**: البيانات حقيقية ومباشرة دائماً.
