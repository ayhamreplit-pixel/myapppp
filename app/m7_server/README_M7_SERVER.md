# 🚀 دليل تشغيل لوحة التحكم وسيرفر البث المحدث لمجلد m7 على AlwaysData (الإصدار المطور)

تم تحديث وتطوير ملف `api.php` في مجلد `m7` ليمنحك **تحكماً كاملاً وشاملاً بجميع بطاقات المباريات، السيرفرات، النتائج، والدقائق** مع تحديث فوري وتلقائي لتطبيق الأندرويد.

---

## 🌟 أبرز المميزات والإضافات الجديدة:
1. **جلب مباريات اليوم، الأمس، والغد أوتوماتيكياً** من مصدر YSScores مع كاش ذكي (25 ثانية لليوم) لمنع الحظر.
2. **إدارة سيرفرات البث المتعددة لكل مباراة**:
   - إضافة أكثر من سيرفر للمباراة الواحدة (مثال: سيرفر 1 FHD، سيرفر 2 HD، سيرفر ضعيف 480p، تعليق عربي صوتي).
   - زر **«فحص»** لتشغيل واختبار رابط البث فوراً عبر مشغل فيديو مدمج (Hls.js) داخل المتصفح قبل حفظه.
   - حذف وتعديل أي سيرفر بنقرة زر.
3. **تعديل كامل لبيانات ونتائج المباريات (✏️ تعديل)**:
   - تعديل نتيجة المباراة المباشرة (أهداف المضيف والضيف).
   - تعديل حالة المباراة (لم تبدأ، مباشر الشوط الأول، مباشر الشوط الثاني، انتهت، تأجلت).
   - تعديل الدقيقة المباشرة (مثال: '75 أو '89).
   - تحديد القناة الناقلة واسم المعلق الرياضي والملعب.
4. **تمييز وإخفاء المباريات**:
   - زر **«★ بالبانر»** لتمييز المباراة وجعلها تتصدر البانر العلوي المتحرك في التطبيق (TOD Hero Slider).
   - زر **«إخفاء»** لإخفاء أي مباراة لا ترغب بظهورها في التطبيق نهائياً.
5. **إضافة مباريات وبطولات مخصصة (+ مباراة جديدة)**:
   - إمكانية إضافة بطولات محلية أو مباريات خاصة غير موجودة في الجداول العالمية مع روابط بثها.
6. **تحديث تلقائي وفوري (Live Polling)**:
   - كود AJAX يقوم بتحديث النتائج والدقائق تلقائياً كل 25 ثانية في لوحة التحكم وبشكل فوري في التطبيق بدون وميض.
   - زر **«⚡ إفراغ الكاش والتحديث»** لجلب أحدث البيانات فورياً من المصدر وتحديث التطبيق.
7. **تصدير واستعادة النسخ الاحتياطية (💾 تصدير نسخة)**:
   - تحميل ملف JSON يحوي كل السيرفرات والتعديلات لحفظها أو نقلها لسيرفر آخر.
8. **فلترة سريعة وبحث متقدم**:
   - البحث بالاسم وفلترة حسب الدوريات والبطولات والتنقل بين التواريخ.

---

## 🛠️ روابط الـ API لتطبيق الأندرويد:
- **جلب مباريات اليوم مع السيرفرات والتعديلات:**
  `https://ayham.alwaysdata.net/m7/api.php?action=matches`
- **جلب مباريات الأمس:**
  `https://ayham.alwaysdata.net/m7/api.php?action=matches&date=yesterday`
- **جلب مباريات الغد:**
  `https://ayham.alwaysdata.net/m7/api.php?action=matches&date=tomorrow`
- **جلب نتائج ودقائق المباريات الحية فقط (خفيف وسريع):**
  `https://ayham.alwaysdata.net/m7/api.php?action=live_scores`

---

## 📌 خطوات التركيب على AlwaysData:
1. افتح https://admin.alwaysdata.com
2. اذهب إلى **Files**.
3. توجه للمجلد `www/m7` (أو أنشئ مجلد `m7`).
4. ارفع ملف `api.php`.
5. افتح لوحة التحكم في المتصفح:
   👉 `https://ayham.alwaysdata.net/m7/api.php`
