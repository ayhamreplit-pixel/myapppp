# دليل رفع ملفات لوحة التحكم والسيرفر إلى AlwaysData (https://ayham.alwaysdata.net)

مرحباً بك! تم تجهيز كافة ملفات الخادم ولوحة التحكم ولوحة متابعة الأجهزة والمشاهدين ("من يشاهد الآن؟") بالكامل داخل المجلد:
`server_backend/`

---

## 📁 قائمة الملفات الجاهزة للرفع:

1. **`index.php`**: لوحة تحكم الأدمن الخارجية (Web Admin Dashboard) باللغة العربية بتصميم TOD لمتابعة الأجهزة المتصلة مباشرة وإضافة المباريات والقنوات واللوقوهات وتعديل النتائج الحية.
2. **`api.php`**: الـ REST API الذي يتصل به تطبيق الأندرويد لجلب المباريات والقنوات وتسجيل نبضات الجلسات (`Session Heartbeat`).
3. **`matches.json`**: ملف قاعدة بيانات المباريات واللوقوهات والنتائج والروابط.
4. **`channels.json`**: ملف قنوات beIN SPORTS والكأس مع الروابط والشعارات.

---

## 🚀 طريقة الرفع على سيرفر AlwaysData في دقيقة واحدة:

1. افتح حسابك في AlwaysData: [https://admin.alwaysdata.com](https://admin.alwaysdata.com)
2. اذهب إلى **Web** > **Sites** وتأكد من أن الموقع يشير إلى المسار الافتراضي `www/` لـ `https://ayham.alwaysdata.net`.
3. اذهب إلى **Drive** > **Files** وادخل إلى مجلد `www/`.
4. ارفع الملفات التالية مباشرة داخل `www/`:
   - `api.php`
   - `index.php`
   - `matches.json`
   - `channels.json`
5. **تمت العملية بنجاح!**
   - يمكنك الآن فتح لوحة التحكم عبر المتصفح: [https://ayham.alwaysdata.net](https://ayham.alwaysdata.net)
   - التطبيق سيتصل فورياً ويجلب كل المباريات والقنوات ويسجل الأجهزة المتصلة من يشاهد الآن في لوحتك!
